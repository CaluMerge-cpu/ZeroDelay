# WebView2 SDK files

Used by the Tournaments tab to show Epic's official schedule (fortnite.com) inside ZeroDelay.

- `Microsoft.Web.WebView2.Core.dll`, `Microsoft.Web.WebView2.Wpf.dll` (lib\net462) and `WebView2Loader.dll` (runtimes\win-x64\native)
- From the Microsoft.Web.WebView2 NuGet package, version 1.0.4258.31: https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4258.31
- Signed by Microsoft Corporation; redistributed under the package's license terms. The Edge WebView2 Runtime itself ships with Windows 11.
